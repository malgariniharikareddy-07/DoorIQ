# DoorIQ — Enhanced front-end prototype

DoorIQ is a responsive student prototype that turns simulated smart-doorbell events into personalized next-step recommendations.

## Interactive features
- Four simulated event scenarios: delivery, expected guest, unknown visitor, and doorbell press
- Three household preferences: busy, available, and safety-first
- Context-aware recommendation and explanation
- Optional household note displayed with the recommendation
- Session activity history with status
- Mark as reviewed and save preference interactions
- Light/dark theme toggle
- Responsive layout for desktop and mobile
- Clear privacy note explaining the simulation

## Run locally
1. Download the project files.
2. Open `index.html` in a modern browser.
3. Choose an event and preference.
4. Click **Translate this event**.

No installation is required.

## Important limitations
This is a front-end prototype using simulated events. It is not connected to Ring devices or Ring APIs. It does not identify visitors, contact couriers, unlock doors, or perform real-world actions. Do not claim a live Ring integration unless a supported, authorized integration is implemented and tested.
